## Careerloom 0.2.0

Two new agent runners built on OpenCode, an India starter pack of job boards in place of ~170 mostly US and European
defaults, and more reliable job evaluation on boards that block scrapers.

### New

- **OpenCode runner** — drives the OpenCode CLI (`opencode run`) headless, with streamed steps, cost and token
  usage, and resumable chat sessions. Runs OpenCode's free models with no account; an OpenCode Zen API key unlocks
  paid models. It may edit files in your career-ops folder and run career-ops' own scripts, nothing else.
- **OpenCode Zen runner** — Careerloom's own built-in agent on the OpenCode Zen API: nothing to install, no CLI
  start-up per run. Uses paid Zen models (cheapest first) with a Zen API key; free models run through the OpenCode
  runner. File access is confined to your career-ops folder (installed skills read-only), commands are limited to
  career-ops' `node` / `npm run` scripts with no shell, and web fetches refuse local and private addresses.
- **Both OpenCode runners work everywhere Careerloom uses an agent**: evaluating jobs, the Agent chat, résumé
  extraction and export, web-board extraction and browser boards (read-only browser tools only).
- **India starter pack** — 24 popular Indian job boards, grouped into Common, Tech, Finance and Consulting, replace
  the ~170 default boards. They start disabled; enable the ones you want. Naukri, LinkedIn and Indeed searches use the
  role and city from your profile.
- **Boards** — a Category column and filter, **Add India starter pack**, and **Switch to India starter pack…**, which
  removes the boards added from the old defaults (keeping boards you added yourself), hides their unevaluated jobs
  and adds the pack.

### Improved

- **Job descriptions for evaluation** — when Firecrawl isn't running or returns nothing, Careerloom reads the
  posting's structured data (schema.org JobPosting) directly, and for boards that block plain requests (Naukri and
  similar) renders the page in Chrome — no agent involved. Workers no longer fail on an empty description.
- **Browser boards** — Careerloom scrolls result lists itself, so the agent navigates, waits once and reads once per
  page (a 3-page LinkedIn scan went from 49 agent turns to 10). Browser tool output stays in each run's private temp
  folder.
- **Lower token use on OpenCode** — only career-ops' own and your installed skills are offered to the agent (about 86%
  fewer input tokens per run).
- **Clearer errors** — OpenCode Zen errors show the provider's own message plus the fix (check the key, pick another
  model, add credits, or use the OpenCode runner for free models).
- **Onboarding and Settings** — OpenCode and OpenCode Zen appear as agent choices, with an OpenCode Zen key field
  stored in your OS keychain and model pickers for both runners.

### Fixed

- **Windows: uploading a résumé** failed with "Pick a file from documents/cv/" (Windows path separators).
- **Onboarding: extracting an uploaded résumé** failed with the same message on every OS.
- **Agent runs started in the wrong folder** with the OpenCode CLI, so evaluation workers couldn't find their job
  files.
- **Chat follow-ups** only resume a session with the runner that started it.

### Install

Download the installer for your system below. Builds are not code-signed yet: on macOS, right-click the app and
choose **Open** the first time; on Windows, choose **More info → Run anyway** in SmartScreen.

- **macOS** — `Careerloom-0.2.0-arm64.dmg` (Apple Silicon) or `Careerloom-0.2.0-x64.dmg` (Intel)
- **Windows** — the Careerloom Setup 0.2.0 `.exe` installer (x64 and ARM64)
