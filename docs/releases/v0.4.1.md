## Careerloom 0.4.1

Careerloom can now update itself, plus a built-in Help center, a rebuilt Overview and Agent screen, and installable
agent skills.

### New

- **Self-update** — Settings › Updates checks GitHub Releases. When a newer version exists, **Update now** downloads
  the build for your computer, verifies its SHA-256 against the checksum GitHub publishes for that file, installs it
  and restarts. Nothing is installed if the checksum is missing or does not match. It asks before stopping runs that
  are still working, and explains when an in-place update is not possible (development builds, running from a disk
  image, a read-only Applications folder).
- **Help center** — a searchable, structured guide to every screen and setting, opened from the sidebar Help button
  or the command palette.
- **Agent skills** — install skills from a Git repository, a folder or a `.zip` in Settings › Skills. You see what a
  skill contains (including any scripts) before it is copied, and skills never update on their own. Enabled skills
  are available to every runner, and the Agent screen has a `/` menu to pick skills for a single message.
- **Images in Agent chat** — attach PNG, JPEG, WebP or GIF images to a message. Runners and models that cannot read
  images say so instead of ignoring them.
- **Rebuilt Overview** — date range control, a pipeline band that links to Jobs, trend sparklines, score histogram,
  applications timeline, source yield, cost and runs, next best actions and a weekly goal ring.
- **Practice sessions** speak the interviewer's questions and use the live answer path.

### Improved

- Agent threads can be renamed; tool steps are grouped and collapsible.
- The command palette search field no longer clips its focus ring.
- The update banner now has an **Update now** button that opens Settings › Updates.

### Notes

- Installers are not code-signed yet. On macOS, right-click the app and choose **Open** the first time; on Windows,
  choose **More info → Run anyway** in SmartScreen.
- Self-update is new in this release, so 0.4.0 installs update to 0.4.1 by downloading the installer manually.
  Later releases can be installed from inside the app.
- Skill folders for Codex and Antigravity follow their current conventions and may need adjusting as those tools
  change. The API runner does not receive skills.
