## Careerloom 0.3.0

Interview Copilot with a job question base and an AI interviewer, a reworked Résumé workspace with a real ATS score,
fast browser boards, a new Settings area and a Windows installer that needs nothing installed first.

### New

- **Interview Copilot (macOS and Windows)** — a floating overlay that listens to your interview and drafts answers
  from your résumé and the job. Local speech-to-text (Whisper on Apple silicon, faster-whisper on an NVIDIA GPU,
  Moonshine otherwise), OpenRouter models with your data-policy setting honoured, adaptive end-of-speech detection,
  optional screenshot questions to vision models, a Privacy mode, global hotkeys and a panic key. Sessions are
  stored per job with a scorecard, answer review and debrief.
  Live sessions need Apple silicon on a Mac, or any Windows PC. System-audio capture is still coming soon.
- **Job question base** — a per-job set of likely questions researched from the web (with a first-run consent,
  budget and robots/private-address safeguards) and matched live during a session.
- **AI interviewer practice** — a Practice page where an interviewer asks, probes and scores your answers, with
  system, Kokoro or OpenRouter voices, then a debrief with a per-question rubric and skill heat map.
- **Résumé workspace** — six pages: Overview, Content, Templates, ATS analysis, Skill-up and Research. The ATS
  score is now computed by code from your real template, split into *Parse health* and *Job match*, with a range
  and confidence. Findings have **Apply**, Skip and Answer-first, with a fact check and Undo; skill gaps come with
  verified courses.
- **Selected job page** — Overview, Job, Report and Documents tabs, with a tailored résumé and cover letter.
- **Runs page** — replaces the side drawer: filters, live runs, a log viewer and grouping by job.
- **Settings** — rebuilt with search, deep links, a key manager with no-token connection tests, runner and
  model pickers, local models, data and retention, and Copilot and Interview prep pages.

### Improved

- **Fast browser boards** — LinkedIn, Naukri, Indeed and Glassdoor boards are read directly over the Chrome
  DevTools protocol (about 25 LinkedIn jobs in 15 seconds, no model cost). The agent is only the fallback.
- **Windows: nothing to install first** — the installer (`Careerloom-Setup-<version>.exe`, x64 and ARM64) now
  ships portable Node.js 22, Python 3.12 and Git inside the app, used only by Careerloom, so a fresh PC needs none
  of them. Installing stays per-user, with no administrator prompt. OpenCode, career-ops dependencies and local
  models are set up on first launch.

### Notes

- The Windows installer is larger (about 310 MB) because of the bundled runtimes.
- Windows support for Copilot (microphone permission, global shortcuts, system voice, GPU speech engine) has not
  yet been tested on real hardware. Please report anything that misbehaves.
- Builds are not code-signed yet. On macOS, right-click the app and choose **Open** the first time; on Windows,
  choose **More info → Run anyway** in SmartScreen. Some antivirus tools can flag bundled Python on first run.
