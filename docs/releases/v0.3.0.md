## Careerloom 0.3.0

### Windows: nothing to install first

The Windows installer (`Careerloom-Setup-<version>.exe`, x64 and ARM64) now ships portable **Node.js 22**,
**Python 3.12** and **Git** (MinGit) inside the app, so a fresh PC needs none of them. Installing stays per-user, with
no administrator prompt. These tools are used only by Careerloom and never touch your system PATH or any existing
Node, Python or Git install.

Everything else (OpenCode, career-ops dependencies, local-model packages and models) is set up on first launch.

### Notes

- The installer is larger (roughly 150-200 MB) because of the bundled runtimes.
- The installer is unsigned. Windows SmartScreen may show "Windows protected your PC": choose **More info**, then
  **Run anyway**. Some antivirus tools can flag bundled Python on first run; allow it if prompted.
- macOS and Linux are unchanged; they fetch the same pinned runtimes (checksum-verified) on first launch.
