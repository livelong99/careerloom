## Careerloom 0.4.0

The first public release: bring your own model provider, pick the model per feature, and a cleaner Integrations page.

### New

- **Model providers** — use your own key with OpenRouter, OpenAI, Anthropic, Google Gemini, Groq, Mistral, DeepSeek,
  xAI, Together AI, Fireworks AI, Cerebras, or any OpenAI-compatible server such as Ollama or LM Studio. Keys stay in
  your operating system's secure storage.
- **Models by feature** — choose the provider and model for helper calls and for the Interview Copilot in
  Settings › Runners & models. The Copilot offers fast models only, because answers are read live.
- **Live model lists** — every model dropdown is a searchable list filled from the provider's own models endpoint,
  from Codex's model cache, from Anthropic's list for Claude Code, and from `agy models`. Any id can still be typed.
- **Copilot "More detail"** — a hotkey (Ctrl+Alt+D on macOS, Alt+Shift+D on Windows) and a link on the answer card
  that expand the current answer with a fuller spoken answer and background.

### Improved

- **Integrations** are grouped by purpose: Core, Job data, Research and Extensions. The career-ops plugin
  marketplace is removed.
- Interface components are now MIT-licensed shadcn/ui, so the whole project is MIT.
- Copilot and settings tests run on Linux CI.

### Notes

- Installers are not code-signed yet. On macOS, right-click the app and choose **Open** the first time; on Windows,
  choose **More info → Run anyway** in SmartScreen.
- Windows support for the Interview Copilot has not been tested on real hardware. Please report anything that
  misbehaves.
