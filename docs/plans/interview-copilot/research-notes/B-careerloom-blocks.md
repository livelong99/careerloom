## 2. Runners (electron/runner.ts, context.ts, zen-agent.ts)
- `RunnerId = 'claude'|'codex'|'antigravity'|'opencode'|'zen'|'api'` (runner.ts:9). `CliRunner` excludes api/zen.
- `startAgentPrompt(label, mode, prompt, input, opts: AgentPromptOptions)` context.ts:363: runner from settings; `api` throws (only fixed commands); `zen` -> `startZen`; else spawns CLI via `argsForPrompt` + `launch`. `AgentPromptOptions = {resume?, env?, onExit?, textOnly?}` (context.ts:361). Returns `RunSummary`; log streamed to renderer via run events.
- Text-only neutral runs: `PromptOptions.textOnly` (runner.ts:81-95): claude `--tools WebSearch,WebFetch`, codex `--sandbox read-only`, opencode `opencodeTextConfig`. Prompt must start with fixed literal (not `-`).
- Streaming: CLIs spawn with `--output-format stream-json` (claude/agy) or `--format json` (opencode); `launch` (context.ts:200) parses stdout lines through `streamFormat(runner)` -> `formatClaudeLine`, `agyFormatter`, `formatOpencodeLine` and appends to run log, broadcast to windows. That is line-level progress, not token-by-token, and spawn startup costs seconds. `runZen` (zen-agent.ts:119) is in-process but uses NON-streaming `fetch(ZEN_URL + '/chat/completions')` with no `stream:true` (zen-agent.ts:68-80), full JSON response per turn, 300 s timeout, retry on 429/5xx, MAX_TURNS 80. No SSE/`getReader`/`text/event-stream` anywhere in electron/ (grep verified). Tool-loop with FILE_TOOLS (`zen-tools.ts`) or MCP browser tools.
- Per-runner helper models: NOT FOUND (no `helperModels`). Model choice is `Settings.models: Partial<Record<ModelRunner,string>>` (context.ts:29; set via `setModel(runner, model)`, `listModels(runner)`); zen resolves via `zenModel(chosen)`.
- OpenRouter 'api' runner: only `node openrouter-runner.mjs <command>` from the career-ops checkout (runner.ts:74), fixed commands, not in this repo.
- Keys: `readSecret/writeSecret` (context.ts:55-64) = Electron `safeStorage` encrypted blob at `userData/<name>.key` mode 0600; names `openrouter` (`readApiKey`) and `opencode` (`readOpencodeKey`). Renderer only sees `hasApiKey`/`hasOpencodeKey` booleans (`getSettings`). `setApiKey(key, provider)`.
- For a streaming copilot runner you can reuse: `readSecret`/`safeStorage`, `zenError`, `ZEN_URL` (electron/opencode.ts), `zenModel`, `broadcast`, `Settings.models`, retry/backoff shape of `complete()`. You need: a new `fetch` with `stream:true` + SSE parser (OpenAI-compatible `data: {choices[0].delta.content}` lines), AbortController wired to a cancel handler, push chunks via `broadcast('careerloom:copilot', ...)` (or `webContents.send` to overlay window only), no tool loop, tiny system prompt, optional history trimming. Claude CLI path is too slow for low latency.
